# 繁中走查（e10-t07）

AC-10.2 的繁中走查紀錄。範圍：`shared/i18n/**` 每一份繁中目錄（`zh-TW.ts`、`zh-TW.common.ts`、`zh-TW.share.ts`、`pages/*.zh-TW.ts`）的每一個值，加上 `shared/templates/**`（清單範本、紐西蘭筆記範本）的繁中文字；並在 375 px 寬的手機畫面實際打開主要頁面看有沒有被字擠爆。用詞規則與術語表見 `docs/DESIGN.md` §5。

> 這是 AI 走查，**建議再請一位台灣母語使用者實際用一輪**（尤其記帳、結算、預訂的說法）。

## 怎麼查的

1. 把每對 zh-TW／en 目錄展開成「key · 繁中 · 英文」對照表逐條讀（約 2,000 條），加上範本 265 段。
2. 機器輔助：搜簡中詞彙（創建、視頻、信息、默認、登錄、用戶、網絡、屏幕、點擊、設置、支持、鏈接、打印、保存、菜單、搜索、數據、程序、緩存…）、「您」、中文句子裡的半形標點、「・」。結果：沒有簡中詞、沒有「您」；半形括號 2 處、「・」2 處（已改）。
3. 375 px 實機：`npm run dev`（本機 D1），用 API 建一趟露營車旅程，兩種語言各開旅程列表、總覽、日程、地圖、清單、記帳、餘額、統計、修改紀錄、預訂、設定、行前清單、預算、文件夾、筆記、回顧、地點庫、照片，程式檢查水平捲動與被裁切的文字，並看截圖。繁中沒有因文案造成的溢出（旅程名稱在頂列被省略號截斷、日期選單左右捲動都是設計如此）。

## 刻意保留

- 「Day {n}」在繁中介面照舊（日程、回顧用 Day，今日卡用「第 {n} 天」），是原本的設計決定。
- 「文件夾」是產品名；「項目」「預設」「透過」是台灣用法。
- 「說明」是花費的描述欄（其他地方叫「備註」），只在記帳相關畫面用，前後一致。
- 「請」只出現在必要的請求句（「請輸入金額」），語氣自然，不刪。
- `docs/PRD/01-travel-domain-notes.md` 仍寫「自炊設備認證」，不在這批可改的範圍，留給下一次文件整理。
