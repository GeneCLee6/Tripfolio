# PRD — Tripfolio · 旅誌（工作名稱）

> 這是產品的總 PRD：願景、範圍、功能需求（F）、驗收條件總表、里程碑與風險。每個 epic 的細節、AC 與 task 拆分在同一個資料夾的 `e*.md`，**勾選狀態以 epic 文件為準**。資料夾的閱讀方式與 task 格式見 [`README.md`](README.md)，旅遊專業角度的領域知識與檢核見 [`01-travel-domain-notes.md`](01-travel-domain-notes.md)，為什麼只分三層見 [`../PLANNING-METHOD.md`](../PLANNING-METHOD.md)。
>
> **名稱已拍板（2026-11-09）**：**Tripfolio · 旅誌**（§14 Q1）。介面預設繁體中文、第一次依瀏覽器語言切英文（§14 Q1b）。**主幣別預設 AUD、第二顯示幣別 TWD**（§14 Q5）；擁有者的旅程型態：紐西蘭露營車環島、峇里島包車、泰國、斐濟、帛琉、歐洲，所以型態範本要有露營車、包車、海島、歐洲鐵路／城市，幣別要涵蓋 NZD、IDR（無小數）、THB、FJD、USD（帛琉）、EUR。

## 1. 願景

**一個給自己和同行朋友用的自由行手冊：規劃時像旅行社的行程頁，出門時像共同錢包。** 先把「一趟旅程寫下來、排在地圖上、分享給朋友」做好，再把「一起出門的每一筆花費誰付、怎麼分」接上去，最後讓旅程結束後同一頁翻面變成遊記。

- **M0 能排行程**：建旅程、拉朋友進來、一天一天排行程點、地圖上看路線與開車時間、口袋名單、唯讀分享連結、繁中／英文。
- **M1 旅行社頁與預訂**：住宿／航班／租車／渡輪的預訂卡與確認信、必吃必買卡片牆、照片、完整的旅行社風格分享頁、列印 PDF、行事曆匯出、範本複製。
- **M2 出門記帳**：成員記帳（多幣別、公基金、五種分法）、餘額與最少轉帳結算、統計與匯出、多人即時同步、離線（PWA＋離線地圖）。
- **M3 旅前準備與回顧**：預算規劃、行前與打包清單範本、文件夾、目的地筆記、倒數與今日卡、回顧模式、用量頁。

基本原則：**只給朋友，不做社群**；**手機是旅途中的主要裝置**；**全部在 Cloudflare 免費額度與免費的地圖服務內**。

## 2. 背景與問題

- 擁有者習慣自己做自由行規劃（例如紐西蘭南島露營車環島 14 天），目前的工具是 Google 試算表＋Google Maps 清單＋LINE 群組＋Splitwise 之類的分帳 app。四個地方各管一塊：行程在表、地點在地圖、討論在群組、錢在另一個 app；出發後朋友問「今天要幹嘛、住哪」還是要翻群組。
- 旅行社的行程頁（每日摘要、地圖、必吃必買、價位）是大家最容易看懂的格式，但沒有一個工具讓個人用那種格式呈現自己的規劃，又能在旅途中變成共同錢包。
- 現成的旅程 app（Wanderlog、TripIt、Polarsteps）各有一塊做得好，但要帳號、要訂閱、沒有繁中、分帳弱或沒有公基金；分帳 app（Splitwise、Tricount）不知道行程是什麼。
- 開發者已有 React＋TypeScript＋Cloudflare Workers／D1／R2／Durable Objects 的經驗（淡江牌桌、LongTalk、TKU Arcade）；地圖（MapLibre）、照片管線、分帳引擎是新題目，但都有成熟的開源路徑。
- 這個站**不營利、不公開招募使用者**；分享連結是給朋友與家人看的，所以全站 `noindex`。

## 3. 目標與非目標

**目標**

1. 一趟 14 天的旅程，從建立到排完每一天並分享給朋友，不需要離開這個 app 查「開多久」。（M0）
2. 分享連結的頁面讓沒參與規劃的人 2 分鐘內看懂這趟旅行：去哪、幾天、每天幹嘛、住哪、要花多少。（M1）
3. 旅途中記一筆花費 ≤ 10 秒；旅程結束結算一張表，每個人看得懂自己該收該付多少、怎麼算的。（M2）
4. 介面預設繁中、可切英文；每一句介面文字都有兩種語言；分享頁也能切。（M0）
5. 沒有訊號的地方（露營車）也能看行程、看地圖、記帳，有訊號後自動同步。（M2）
6. 行前該辦的事（簽證、保險、國際駕照、海關）有一份依旅行型態帶入的清單。（M3）
7. 全程 0 元雲端費用：Cloudflare 免費額度、OpenFreeMap／Photon／ORS 免費方案。（全程）

**非目標**

- 公開社群、探索別人的旅程、追蹤、按讚、留言。
- 訂房、訂機票、比價、聯盟行銷。
- 即時導航（開車用 Google Maps／Apple Maps，我們提供「用地圖 App 開啟」）。
- AI 自動排行程（之後可以當玩具，不在前四波）。
- 原生 App（PWA 即可）。
- 帳號密碼系統（邀請連結＋選用 Google 登入）。

## 5. 產品原則

1. **旅程是容器**：一切（日程、地點、住宿、清單、照片、花費、文件）掛在一個旅程下；刪旅程就乾淨。
2. **連結就是門**：邀請連結進來編輯、分享連結進來看；帳號是加分不是門檻。
3. **地圖與時間一起算**：行程點有座標就自動算移動時間；排太滿、沒開、天黑了要提示。
4. **錢要算到分**：整數分運算、每筆可展開看每人分到多少、匯率永遠可手動改並標來源。
5. **離線是常態**：旅途中的動作（記帳、勾選、看行程、看地圖）都要能離線完成。
6. **繁中來源、英文並列**：字串表以繁中為來源、英文是翻譯；缺翻譯顯示繁中，CI 擋缺漏。
7. **像雜誌不像儀表板**：米白紙感、襯線標題、大照片、留白（`DESIGN.md`）。
8. **隱私最少化**：成員只有名字；文件夾永不分享；全站 noindex；刪旅程連帶刪媒體。

## 6. 競品與定位

| 工具 | 做得好的 | 缺的（我們要做的） |
| --- | --- | --- |
| Wanderlog | 行程＋地圖＋路線時間、匯入預訂 | 要帳號、進階付費、沒有繁中、分帳只有基本、沒有公基金 |
| TripIt | 預訂 email 自動匯入、時間軸 | 不是規劃工具、沒有地圖路線、沒有分帳 |
| Polarsteps | 旅途足跡與相簿、遊記 | 不是規劃工具、沒有分帳 |
| Splitwise／Tricount | 分帳、多幣別、結算 | 不知道行程；Splitwise 多項功能付費；沒有公基金 |
| Notion／Google 試算表 | 自由、大家會用 | 沒有地圖、沒有路線時間、分帳要自己寫公式、手機難用 |

定位：**「旅行社行程頁」的呈現 ＋「Wanderlog」的地圖與路線 ＋「Tricount」的免帳號分帳 ＋ 台灣朋友的公基金**，只給朋友用。

## 9. 非功能需求

- **效能**：主 app 首屏 JS gzip ≤ 180 kB；分享頁 ≤ 120 kB；MapLibre 獨立 chunk ≤ 300 kB（2026-11-09 由 250 調高，見 ARCHITECTURE §6）、lazy；分享頁 Lighthouse 手機效能 ≥ 90；日程頁 100 個行程點拖曳不掉格。
- **離線**：最近 3 個旅程的資料、旅程外框 zoom 5–12 的瓦片（≤ 150 MB）、路線 JSON 可離線；離線佇列在連線 10 秒內送完。
- **同步**：兩個編輯者互見 ≤ 3 秒；欄位級合併不丟整筆。
- **正確**：金額以整數分運算；分攤總和等於原金額（測試）；時區用 UTC＋IANA，測試涵蓋跨日與夏令時間。
- **成本**：Cloudflare 免費額度（Workers 10 萬請求／日、D1、R2 10 GB、DO）；外部 API 免費方案（ORS 2,000／日、Photon 公平使用、匯率 API 免費層）；用量頁與 80% 警示。
- **相容**：Chrome／Edge 最近兩版、Safari 17+（iOS PWA）、Firefox 最近兩版；手機 375 px 起。
- **無障礙**：鍵盤可達、焦點可見、對比 AA、拖曳有鍵盤替代、reduced motion、觸控 44 px、axe 無 serious。
- **安全與隱私**：三種 token 128-bit 存雜湊；文件類只經 Worker 驗權；分享頁伺服器端過濾；全站 noindex；CSP；個資最少化；符合台灣個資法的精神（最少蒐集、可刪除）。
- **i18n**：zh-TW 來源、en 翻譯、CI 擋缺漏；`Intl` 格式；地點中英名並存。

## 13. 風險

| 風險 | 對策 |
| --- | --- |
| 免費地圖／路線／搜尋服務停用或改條款 | provider 是設定值；後備 Protomaps（R2 自託管）、Nominatim、直線估算；`ARCHITECTURE.md` §5 有切換步驟 |
| 外部 API 配額用完 | Worker 代理＋快取＋每成員速率限制＋配額計數與警示 |
| 分帳算錯一分錢，朋友不服 | 整數分、餘數規則公開、每筆可展開；純函式完整測試 |
| 匯率不等於刷卡匯率 | 永遠可手動覆寫並批次套用；標示來源 |
| 範圍太大一個人做不完 | 四個里程碑各自可用；M0 就能解決「紐西蘭怎麼排」；M2 之前不做花費 |
| 隱私：護照影本、住宿地址外洩 | 文件只經 Worker 驗權、永不分享；分享頁伺服器端過濾；全站 noindex；token 可撤銷 |
| 離線與即時同步互打 | 單一 `useTrip()` 管線，佇列就是未送出的 patch；欄位級後寫贏，不做 CRDT |
| R2 10 GB | 只存 2048 版、容量警示、封存旅程可清照片 |
