## 讀的順序

| 情境 | 讀 |
| --- | --- |
| 第一次看這個專案 | `00-prd.md` §1–§7，然後 `01-travel-domain-notes.md` §1–§3、§6 |
| 開工做某一批 | `../NEXT.md` → `../ROADMAP.md` 的該批 → 該批 task 所在的 epic 段落 |
| 想知道某個功能做到哪 | 該 epic 的 AC 勾選 → 下面的進度表 |
| 分帳怎麼算、公基金怎麼退 | `e7-expenses-splitting.md` ＋ `01-travel-domain-notes.md` §6 |
| 地圖服務怎麼換 | `../ARCHITECTURE.md` §5 |

## Task 格式

```
- [ ] `e<epic>-t<nn>` 一句話說明 · AC-<epic>.<n> · S|M|L · ← 前提 task
```

- `S` ≈ 半天、`M` ≈ 1–2 天、`L` ≈ 3 天以上（L 要拆；已拆的用 `t08a`／`t08b`）。
- 做完改 `[x]` 並在句尾寫 PR 號（`#12`）。
- AC 有驗證（測試或實測）才勾。
