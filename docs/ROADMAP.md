# ROADMAP — 開發路線圖（2026-11-09 版）

這是從零到「M3 旅前準備與回顧」的**全部順序**。一批 = 一個 PR = 一個 AI session。照批次號依序做，不跳批；每批做完在這裡把 `[ ]` 改成 `[x]` 並寫上 PR 號，同時更新 `docs/NEXT.md`「現在的位置」與 `docs/PRD/README.md` 進度表。task 的細節在各 epic。

Phase 用字母，**跳過 E 與 M**（避免和 Epic 編號 E1…E11、里程碑 M0…M3 混淆）。

**完成的定義**：
- 做完 **Phase A–C** ＝ **M0 能排行程**：旅程、成員與邀請、日程與行程點、地點與地圖、路線與駕駛時間、口袋名單、分享連結基本版、雙語、部署與備份。擁有者排完紐西蘭南島 14 天並分享給一位朋友。
- 做完 **Phase D、F** ＝ **M1 旅行社頁與預訂**：照片、必吃必買、住宿與交通預訂、附件與期限、完整分享頁、列印、ICS、範本與匯出、隱私。
- 做完 **Phase G–H** ＝ **M2 出門記帳**：分帳引擎、記一筆、公基金、結算、統計、PWA 與離線、離線地圖、即時同步、安全、Google 登入。實際出遊用一趟。
- 做完 **Phase I–J** ＝ **M3**：清單範本、目的地筆記、預算、文件夾、倒數與今日卡、照片配對與相簿、回顧模式、用量頁。

開工指令（貼給 Claude，建議 Opus、effort medium）：

```
讀 CLAUDE.md、docs/NEXT.md、docs/ROADMAP.md。做 ROADMAP 第 <批次號> 批，照 NEXT.md 第 3 點的規則：
worktree 開分支、只讀需要的段落、lint+typecheck+test+build 只看最後 5 行、一批一個 ready PR（標題列出全部 task 編號、本文寫 AC 與檢查）、
在 PRD 勾選並更新進度表、在 ROADMAP 勾選這一批並寫 PR 號、更新 NEXT.md「現在的位置」，CI 綠了直接合併（需要人決定的事才停），合併後回報並結束。
介面文字一律走 i18n（zh-TW 來源、en 翻譯），外部 API 一律經 Worker 代理並計數，金額一律整數分；離線與同步的 AC 要在兩台裝置實測才能勾。
```
